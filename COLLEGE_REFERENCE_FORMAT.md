# College reference form

The website, PDF and Excel now use the reference form's monochrome ruled format: college and department headings, term/academic-year and commencement-date rows, year/semester/division fields, numbered periods, a single vertical recess column, four adjacent legends, and prepared/verified, college-seal and approval spaces.

Term, academic year and commencement date are blank because the saved configuration does not provide them. Signature and seal spaces are intentionally unsigned; no signatures or college stamp were copied from the photo. Names in the timetable and legend come from the saved timetable. The timetable cells retain the generated assignments, not the example timetable's assignments.

PDF creates one landscape A3 form per selected timetable with embedded fonts. Excel contains real merged cells and prints each sheet on one landscape A3 page. Both retain merged full-duration practical/project cells and separate parallel batches. The browser uses the same geometry; the information button is revealed on hover or keyboard focus.

All scheduling and optimisation modules and the supplied database are unchanged. There is no need to regenerate an existing successful timetable. Stop the app, back up/preserve your current data folder when upgrading, restart, and press Ctrl+F5.

Validation: geometry tests cover all division, professor, classroom and laboratory views, continuous recess spans, Excel merges, nonoverlapping cells and unchanged source entries. Browser checks passed for all views and the free-resource dialog. The eight-division PDF contains eight pages.
