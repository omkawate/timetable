# Auto classroom for batch practicals

Academic setup → Assignments → edit the required IKS batch assignment → Laboratory / project room → Auto classroom → Save. Repeat for each IKS batch that should use a classroom, then generate a new timetable.

The choice applies to practical (lab) sessions only, not projects. Existing assignments default to laboratories. No academic data was automatically changed. Each batch remains separate. Two-hour practical duration, teacher assignments, weekly session counts, classroom continuity, and conflict checks remain unchanged. Capacity, department and year eligibility are enforced. Classroom-based practicals are labelled explicitly in the timetable and exports. JSON, Excel and extended CSV backups preserve this choice.

Existing saved timetables keep their original allocation. Refresh the browser with Ctrl+F5 after updating.
